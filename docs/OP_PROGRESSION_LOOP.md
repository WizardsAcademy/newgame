# چرخهٔ OP — پیاده‌سازی کامل

سه چیز خواستی:
1. **skill tree اضافه می‌شه، damage اضافه می‌شه** → در آخر **همیشه** بتونی OP بشی
2. **یه ستون ability** توی بازی می‌خوای
3. **سبک بازی روگ‌لایک** — باید بمیری، آپگرید کنی، برگردی، تا سری بعد قوی‌تر باشی

هر سه تا پیاده شد. پَچ: `docs/patches/op_progression_loop.patch`

---

## ۱. باگی که همه‌چیز رو می‌شکست

**`_show_upgrade_menu()` هیچ‌وقت صدا زده نمی‌شد.**

```gdscript
// main.gd — قبل
func _show_upgrade_menu() -> void:     // تعریف شده
    ...                                  // ولی هیچ‌جا سراغش نمی‌رفتن!
```

یعنی دقیقاً همون چیز که تو خواستی — «upgrade کنی، بری دوا» — **وجود نداشت**. تنها رشد، skill tree بود که اونم کنده.

الان:
```gdscript
func _after_stage_reward() -> void:
    if player != null and not game_is_over:
        if world_mode == WorldMode.SANDBOX or _run_has_banked_upgrade:
            pass
        else:
            _run_has_banked_upgrade = true
            player.input_enabled = false
            _show_upgrade_menu()     // ← حالا هر wave
            return
```

**هر wave که تموم کنی، ۳ کارت می‌بینی و یکی رو انتخاب می‌کنی.** حالا چرخهٔ روگ‌لایک کار می‌کنه.

---

## ۲. `[R]` هیچ کاری نمی‌کرد

این باگ بدتری بود. `player_base.gd` این رو می‌خوند:

```gdscript
if event.is_action_pressed("ultimate"):
```

ولی **`ultimate` توی `project.godot` وجود نداشت**. و بدتر: `R` به `restart` وصل بود!

یعنی اگه `[R]` رو می‌زدی، **بازی restart می‌شد**. Ultimate هرگز فعال نمی‌شد.

**درست شد:**
- `ultimate` → `R` (اکشن جدید)
- `restart` → `Enter` (تا با R تداخل نداشته باشه)
- `special` → `RMB` / `Q` (اکشن جدید)

---

## ۳. ستون Ability (چیزی که خواستی)

دو تا چیز:

**الف) نوار Ability** — پایین-راست، `[LMB] [RMB] [SHIFT] [R]` با cooldown واقعی و حالت `LOCK`.

این از قبل وجود داشت، ولی `RMB` یه عدد ثابت `0.0` نشون می‌داد چون هیچ ability ای بهش وصل نبود. الان cooldown واقعی داره.

**ب) ستون نور (Ability Pillar)** — یه ستون عمودی که **وقتی ability می‌زنی روشن می‌شه** و بعد محو می‌شه:

```gdscript
# hero_hud.gd
_pillar_rect = ColorRect.new()
_pillar_rect.name = "AbilityPillar"
_pillar_rect.size = Vector2(3.0, 54.0)
```

تشخیص «ability زده شد» از این راه: اگه cooldown یهو از ۰ بالا رفت، یعنی ability فعال شد.

```gdscript
if cd_left > prev_cd + 0.05:
    _pillar_glow = 1.0
```

**چهار ability جدید** (RMB/Q):

| هیرو | Ability | اثر |
|---|---|---|
| **Behemoth** | Earthshatter | ضربهٔ ۳۶۰ درجه، ×۱.۶ دمیج، شعاع ۹۶ |
| **Knight** | Holy Smite | ×۱.۴ دمیج شعاعی + ۰.۵ ثانیه invulnerable |
| **Sylvara** | Ranger's Volley | ۳ تیر پنکه‌ای، هرکدوم ۷۰٪ دمیج |
| **Noa** | Sanguine Burst | Fang Burst اجباری بدون توجه به combo |

## ۴. سقف هیرو — حالا بی‌نهایت

اینجا مشکل ریاضی بود. درخت بعد از ۱۴ نود **تموم می‌شد**:

- سقف دمیج = ۱۸ پایه + ۲۰۰ از نودها = **۲۱۸**
- با Frenzy ×۱.۹ و `[R]` ×۲ و uptime → **۵۵۲**

ولی دشمن `30 × 1.85^(w-1)` بود → wave 15 می‌شد **۱۶۵,۰۰۰ HP**.

**راه‌حل: نود `Ascension`** — بی‌نهایت سطح (تا ۹۹۹)

```
+25% دمیج  +25% HP  +15% انرژی  — به ازای هر سطح
```

**مهم: ضربی‌ست، نه جمعی.** اگه `+6` جمعی بود، بعد از wave ۳۰ باز هم می‌باختی. با `×۱.۲۵` و یه سطح در هر wave، **همیشه** از دشمن جلو می‌زنی.

## ۶. نقطهٔ ۱۵ — چرا اینجا؟

سختی از یه «دیوار» بی‌نهایت (قبل) شده یه «تپه» که ازش بالا می‌ری. علتش اینه:

- تا wave ۱۴: درخت رو پر می‌کنی (۱ پوینت در هر wave)
- از wave ۱۴: هدفت **Ascension** ئه

بازهٔ بین ۱۴ تا ۲۰ سخت‌ترین بخشه — و این **درسته**. تو یه روگ‌لایک باید این‌جوری باشه: یه بازهٔ فشار که با پیشرفت شکسته می‌شه.

---

## ۷. اقتصاد پوینت

قبل: `REAGENTS_PER_POTION = 3` → **۳ wave = ۱ پوینت** → پر کردن درخت ۲۱۰ wave می‌خواست.

الان: `REAGENTS_PER_POTION = 1` → **۱ wave = ۱ پوینت**.

با ۷۰ پوینت درخت پر می‌شه، از اون به بعد همه‌چیز می‌ره Ascension.

## ۹. چیزی که **نه** درست شد

یه محدودیت هست: **اسکیل‌های Save قدیمی.**

اگه قبلاً روی `main` بازی کرده باشی، `user://witch_cottage_save.cfg` ممکنه نودهای قدیمی (`vitality`, `wrath`) داشته باشه. کد این‌ها رو نادیده می‌گیره (چون `ALL_NODE_IDS` عوض شده)، پس **بازی نمی‌شکنه** — فقط پوینت‌های قدیم کار نمی‌کنن. اگه مشکل دیدی، `canoheil` رو بزن یا فایل سیو رو پاک کن.
