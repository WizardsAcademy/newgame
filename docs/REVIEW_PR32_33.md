## ۴. تنها چیز جدی که باید بدونی: **بالانس ریاضی خرابه**

این مهم‌ترین یافتهٔ این بررسیه. PR #33 این رو اضافه کرد:

```gdscript
return region_mult * pow(1.85, float(w - 1))   // HP
return region_mult * pow(1.26, float(w - 1))   // Damage
```

عددش رو حساب کردم:

| Wave | ضریب HP دشمن | ضریب دمیج دشمن |
|---|---|---|
| 1 | 1× | 1× |
| 5 | **11.7×** | 2.5× |
| 10 | **253.8×** | 8.0× |
| 15 | **5,500×** | 25.4× |
| 20 | **119,196×** | 80.7× |

**توضیح انسانی:**

- **Wave 5** — یه اسلایم عادی ۱۱.۷ برابر HP داره. اگه با یه ضربه می‌مرد، الان ۱۲ ضربه می‌خواد.
- **Wave 10** — ۲۵۴ برابر. یه اسلایم معمولی می‌شه یه باس.
- **Wave 15** — ۵,۵۰۰ برابر. با بیشترین دمیج ممکن (حدود ۲۱۸)، **۲۵۲۳ ضربه** لازمه برای **یه** دشمن عادی.

و دمیج دشمن هم ۲۵ برابر می‌شه. تو نوآ با ۱۲۰ HP، **یه ضربه** از یه اسلایم تو wave 15 می‌کشتت.

**یعنی:** هر ران بعد از wave 8-9 ریاضیاً غیرقابل‌بازی می‌شه. نه سخت — **غیرممکن**.

راه‌حل: یا `1.85` رو بکن `1.25`، یا دمیج بازیکن رو هم به همون نسبت نمایی کن. الان یکی نمایی شده، اون یکی خطی.
